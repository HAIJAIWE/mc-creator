# 可视化低代码造 Mod 操作指南

> 适用版本：v0.1.0 | 面向：第一次用节点图做 Mod 的用户
> 前置：应用已启动（`pnpm dev` 弹出桌面窗口，或浏览器打开 dev 地址）

---

## 1. 一分钟总览

```
仪表盘（选 Mod）→ 工作台 → 中间区「低代码」tab → 左侧拖节点 → 连线 → 🪄排版 → 编译并应用 → 代码 tab 看文件 → 导出
```

- **低代码目前只支持 Mod 项目**（Fabric / NeoForge / Quilt）。数据包、资源包、皮肤等其他类型请用右侧 AI 智能体 + 表单 + 专用预览面板（见第 6 节）。
- 节点图 ↔ Spec 双向同步：AI 生成的 Spec 可以一键渲染成节点图（`⇄ 从 Spec 导入`），节点图也可以编译回 Spec。

## 2. 进入低代码工作区

1. 仪表盘点击 **Mod** 卡片（新建）或打开一个已有 Mod 项目。
2. 中间区顶部 Tab 点 **低代码**。
3. 顶部模式切换确认在 **L1 低代码**（L2 混合允许代码节点，L3 纯代码跳到文件编辑器）。

工作区四部分：

| 区域       | 位置             | 作用                                                                  |
| ---------- | ---------------- | --------------------------------------------------------------------- |
| 节点库     | 左 220px         | 按分类列节点 + 搜索 + 模板 + 自定义节点                               |
| 画布       | 中间             | React Flow 画布，拖拽/连线/框选（拖拽实时吸附 24px 网格，松手落网格） |
| 属性抽屉   | 点节点后右侧滑出 | 改选中节点的字段（复杂字段；数字/文本/开关也可在积木行内直接改）      |
| 顶部工具栏 | 顶部             | 撤销/重做、导入导出、存盘、🪄排版、👁预览、编译并应用、调试            |

## 3. 实战：5 分钟做一把「红宝石剑」

### 3.1 放物品节点

- 节点库 **内容节点** → 把 **物品** 拖到画布（会自动吸附网格，并自动连上最近的上方兼容节点）。
- 拼图积木的数字/文本/开关行可直接点值行内改（回车提交，Esc 取消；已连线的行只读，边优先）；复杂字段点积木右上角 ⚙️ 去右侧抽屉改：`itemId = ruby_sword`，`displayName = 红宝石剑`，`category = sword`，`maxDamage = 500`。

### 3.2 放配方节点并连线

- 拖一个 **配方** 节点到物品下方。
- 从物品节点**底部**手柄拖到配方节点**顶部**，自动生成黄色 `craft` 连线。
- 点配方节点：`recipeId = ruby_sword_recipe`，`recipeType = crafting_shaped`。

### 3.3 整理 + 编译

1. 点顶部 **🪄 排版** → 自动变成竖向流程图。
2. 点 **编译并应用** → 右上角徽章显示 `✓ 编译通过`（有错会红框标出节点，点节点看抽屉里的错误详情）。
3. 切中间区 **代码** tab：能看到生成的 `ModItems.java`、配方 JSON 等文件。
4. 切 **预览** tab：结构化查看物品/配方。

### 3.4 保存你的图

- **💾 存盘**：存为 `.json` 到磁盘（可分享、可进 git）。
- **⬆ 导出 / ⬇ 导入**：浏览器下载/上传节点图文件。
- **🕘 最近**：快速打开最近的图。
- 快捷键：`Ctrl+Z` 撤销、`Ctrl+Shift+Z`/`Ctrl+Y` 重做、`Ctrl+D` 复制选中节点、`Del` 删除、`Esc` 取消选中。

## 4. 实战：右键木棍召唤闪电（事件逻辑）

1. 拖 **事件** 节点：`eventType = player_right_click_block`。
2. 拖 **条件** 节点：`conditionType = has_item`，参数 `{"item":"minecraft:stick"}`。
3. 拖 **动作** 节点：`actionType = spawn_entity`，参数 `{"entity":"minecraft:lightning_bolt"}`。
4. 连线（紫色 `control` 虚线）：事件底部 → 条件顶部；条件 `true` 口 → 动作顶部。
5. 🪄排版 → 编译并应用 → 代码 tab 看生成的事件处理器。

连线规则（拖线时自动校验，不合法落不上去）：

| 源 → 目标                                 | 连线      | 颜色   |
| ----------------------------------------- | --------- | ------ |
| event/condition/action → condition/action | control   | 紫虚线 |
| item → recipe                             | craft     | 黄实线 |
| block → multiblock                        | structure | 紫实线 |
| item/block → machine                      | flow      | 绿实线 |
| 其他                                      | data      | 灰实线 |

## 5. 进阶功能

| 功能         | 入口                             | 说明                                                                                                        |
| ------------ | -------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| 模板一键开局 | 节点库底部 📦 模板               | 11 个内置模板（空白/简单物品/武器/机器/事件监听/自定义代码/熔炉配方/发电机…），加载前会确认（替换当前画布） |
| 从 Spec 导入 | 顶部 `⇄ 从 Spec 导入`            | AI/表单产出的 Spec 渲染成节点图；vanilla 引用物品会自动生成引用节点                                         |
| 实时代码预览 | 顶部 👁 预览                      | 右侧展开，边搭边看生成的 Java                                                                               |
| 调试器       | 顶部 🐛 调试（有编译错误时可用） | 自动在错误节点打断点，底部面板单步执行，画布青色高亮当前节点                                                |
| 封装子图     | 框选多个节点 → 右键 → 封装为子图 | 复用逻辑块，支持嵌套；双击进入子图编辑                                                                      |
| 过程节点     | 逻辑节点 → 过程                  | 命名可复用逻辑，编译为 Java 方法（对标 MCreator procedure）                                                 |
| 自定义节点   | 节点库 🧩 自定义节点 → 导入      | 粘贴 JSON Schema 即可扩展自己的节点类型                                                                     |
| 新手引导     | 顶部 `?`                         | 5 步引导，随时重看                                                                                          |

## 6. 非 Mod 类型怎么做

低代码画布目前仅支持 Mod。其他 12 种类型走这条路：

1. 右侧 **AI 智能体** 描述需求 → **生成 Spec** → **生成文件**。
2. 中间区 **预览** tab 看结构化结果（每种类型有专用面板）。
3. **代码** tab 精改，**资源/NBT** tab 处理贴图与数据。
4. 顶部工具栏导出 ZIP / 保存项目。

常用入口：

| 想造                            | 做法                                       |
| ------------------------------- | ------------------------------------------ |
| 数据包（函数/配方/进度/掉落表） | AI 生成 → 预览 tab 审阅 → 代码 tab 改 JSON |
| 资源包（贴图/模型/语言/音效）   | 资源 tab 实时预览 + 语言表编辑             |
| 皮肤                            | 皮肤预览 tab，skinview3d 3D 预览           |
| 服务器/启动器                   | 对应预览面板填表单                         |
| KubeJS / CraftTweaker           | 对应预览面板分类管理脚本                   |
| 基岩版行为包/物品/实体          | 对应预览面板 + 表单                        |

## 7. 常见问题

| 现象                         | 原因 / 解法                                                                |
| ---------------------------- | -------------------------------------------------------------------------- |
| 拖线落不上去                 | 端口类型/方向不兼容（看端口颜色与 Tooltip）；`multiple=false` 的口已有连线 |
| 编译红框标节点               | 点该节点 → 右侧抽屉看编译错误详情，改完重编                                |
| 画布乱了                     | 点 🪄 排版一键整理                                                         |
| 误操作                       | `Ctrl+Z` 撤销（50 步）；大改前先 💾 存盘                                   |
| 切到其他类型后画布提示不支持 | 正常：切回顶部类型 = Mod 即可继续                                          |
| 想从代码反推回节点           | L3 纯代码顶部有「降级到低代码」按钮（AST 提取，复杂文件可能不完整）        |
