# Design Context — MC Creator

## Target audience
Minecraft 内容创作者：从硬核模组开发者到休闲玩家。技术层级跨度大，但都对 Minecraft 的视觉语言（方块、像素、草绿、泥土、可 crafted 的手感）高度熟悉且有感情。桌面端 Electron 应用，无 Web 性能/响应式硬约束。

## Use cases
- 用自然语言描述需求 → AI 生成 Mod / 数据包 / 整合包 / 材质 / 皮肤 / 资源包
- 可视化编辑 Spec（JSON）、管理文件树、一键构建 .jar / 导出 zip
- 从 Modrinth / CurseForge 搜索并加入整合包
- 项目管理（保存 / 导入 / 导出）

## Brand personality / tone
**Minecraft craft（方块像素风）**，不是又一个 VS Code 克隆。
- 关键词：方块感、可 crafted、草绿、泥土棕、低调像素底纹、立体凸起按钮（模拟游戏内方块）
- 情绪目标：亲切、有创造力、一眼认出「这是做 MC 的」
- 单一强调色 = 草绿（creeper green），语义色：经验金（警告）、红石红（错误）

## Design constraints
- 技术栈：Electron + React 18 + Tailwind v3 + Monaco 编辑器 + Zustand
- 设计 token 单一事实来源在 `src/renderer/src/index.css` 的 `:root` CSS 变量，经 `tailwind.config.js` 暴露为 `mc-*` 工具类
- 圆角极小（方块感）：`rounded-mc`(3px) / `rounded-mc-lg`(6px)，禁止大圆角
- 动效：指数缓出 `var(--mc-ease)`，**不回弹**；仅状态变化动效
- 字体：display/body 用无衬线系统栈 + 粗重字重做「方块感」；代码用等宽
- 对比度：次文字最低 `mc-text-dim`（≥5:1），装饰用 `mc-text-mute`
- 主题切换：LayoutConfig 改写 `--mc-accent*` 变量实时换肤（草绿/下界/海洋/暮色）

## Differentiation
区别于通用 IDE 的「蓝 + 深色 + 圆角卡片」AI 默认审美，用 Minecraft 原生视觉语言建立品牌记忆点。
