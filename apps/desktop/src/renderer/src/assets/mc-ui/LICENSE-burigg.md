# 第三方许可 · burigg/minecraft-inventory-ui（vendor 片段）

本项目 `src/renderer/src/components/McInventory.tsx` 的**布局几何**（槽位尺寸 / 内边距 /
间隙 / 快捷栏偏移 / 面板尺寸）vendor 自以下开源项目，并做了版权安全改造
（移除 Mojang 原版背景图与物品贴图，改用本项目 CSS 面板 + 自有 CC0/CC-BY 图标）。

> 原仓库：https://github.com/burigg/minecraft-inventory-ui
> 原组件：src/components/Inventory.tsx
